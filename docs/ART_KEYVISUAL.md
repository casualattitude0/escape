# Escape — 主視覺（Key Visual）

> 總則與上色本模型見 [ART_STYLE.md](ART_STYLE.md)；場景細則見 [ART_SCENE.md](ART_SCENE.md)；角色細則見 [ART_CHARACTER.md](ART_CHARACTER.md)。

**這張圖是《Escape》的北極星主視覺**——所有場景、行銷、封面、載入畫面的最終氣質，都要能被這張圖解釋。它把 [ART_STYLE.md](ART_STYLE.md) 的「上色本模型」一次講完：**黑白線稿的巨構世界，白底高明度，一個渺小的角色站在其中。**

---

## 1. 這張圖是什麼

一個**俯瞰 / 墜落視角**灌進一座垂直巨構的維修井。純白基底、灰階排線、強黑墨線撐起所有結構：

- **巨構機械內部**：纏繞的管線、艙門、鋼樑、儀器層層堆疊，尺度大到壓迫，讀得出「有巨大的東西」卻讀不懂它的空間邏輯。
- **開向宇宙的巨窗**：結構縫隙開向一顆坑坑疤疤的行星 / 月球與遠方的尖塔城市——把「秘密收容設施」放進一個更大、更不可名狀的世界。
- **手寫編號 `04`**：大大地寫在結構面板上，是 SCP 味的縫線，也是房間身分（呼應 [ART_SCENE.md](ART_SCENE.md) §6）。
- **渺小的角色**：右下角一個小小的人形（帶著一隻小夥伴 / 貓頭鷹）——**唯一的「人」**，用比例把巨構的龐大頂到最大。
- **光**：白色天光從結構縫隙灌下，畫面明亮、沒有純黑大色塊——**受限視野靠淡灰虛化，不靠壓黑**。

---

## 2. 它示範了哪幾條鐵律

| 鐵律 | 這張圖怎麼做到 | 出處 |
|------|----------------|------|
| **白底高明度** | 底是純白，不是灰或黑；整體明亮不壓抑 | [ART_STYLE.md](ART_STYLE.md) §北極星 |
| **強黑線是主角** | 粗實墨線描出每一根管、每一道艙門 | [ART_SCENE.md](ART_SCENE.md) §1 |
| **灰階只給陰影 / 景深** | 排線灰階把遠處推後，彩度為零 | [ART_SCENE.md](ART_SCENE.md) §1、§3 |
| **遠景詭譎、近景誠實** | 深井背景矛盾透視撐 SCP 感；角色腳下結構可讀 | [ART_SCENE.md](ART_SCENE.md) §2 |
| **手繪至上** | 看得出是人用筆畫的抖線，不是乾淨向量 | [ART_STYLE.md](ART_STYLE.md) §共同紀律 1 |
| **手寫編號標籤** | `04` 直接寫在結構上 | [ART_SCENE.md](ART_SCENE.md) §6 |
| **渺小人形定尺度** | 一個小角色頂出巨構的壓迫感 | [ART_SCENE.md](ART_SCENE.md) §2 |

## 3. 它「缺」的那一味（刻意的）

這張參考圖是**純黑白**——因為它示範的是**世界**。上色本模型的另一半在角色：

> **把一隻鮮豔糖果色的角色壓到這張圖上，那一塊飽和色會在純白線稿世界裡跳到最亮。** 那就是完成的《Escape》主視覺。

- 場景永遠維持這張圖的黑白；彩度全留給角色（[ART_CHARACTER.md](ART_CHARACTER.md) §4）。
- 唯一允許的場景色光：管道內壁透一圈 Runner 招牌色微光、升壓時的警示紅脈動燈（[ART_SCENE.md](ART_SCENE.md) §1、§5）。

## 4. 用途與自檢

**用在哪**：Steam 封面 / 商店主圖、載入畫面、關卡過場、行銷 KV、美術對齊時的「這對不對」基準圖。

**自檢**（新場景圖 / KV 出稿前，逐條對照這張參考）：

- ✅ 底是**純白**，不是灰或黑？
- ✅ 結構靠**強黑墨線 + 灰階排線**撐起，沒有飽和彩色？
- ✅ 有**渺小人形**或可辨物件定尺度？
- ✅ 有至少一個**手寫編號 / 標籤**縫進結構？
- ✅ 遠景**矛盾透視退到後面**、腳下結構誠實可讀？
- ✅ 明亮、沒有**純黑大色塊**壓暗畫面？
- ✅ 想像壓一隻**糖果色角色**上去時，那塊彩色會不會跳出來？

任何一條打叉，就還沒對到這張主視覺。
