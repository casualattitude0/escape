# Escape — 角色視覺風格（Character Art Style）

> 場景風格見 [ART_SCENE.md](ART_SCENE.md)；共用總則與上色本模型見 [ART_STYLE.md](ART_STYLE.md)。

**角色在上色本模型裡是「唯一被上色的東西」**——鮮豔糖果色，壓在純白黑白線稿的世界上，跳到最亮。錨點是 `concepts/Collections.pdf` 的角色手稿，以下原則都是從那疊塗鴉反推出來的。

---

## 1. 定調

**手繪塗鴉感的「明亮版可愛驚悚」——派對感的萬聖節糖果玩偶（Spooky-Cute Party）。**

參考坐標：*Fall Guys*、*Luigi's Mansion* 派對模式、*Costume Quest*、*Overcooked*。萬聖節的骷髏南瓜吸血鬼都在，但它們是**糖果色的玩偶**，不是嚇人的鬼。

- **可愛在先，怪只是點綴**：第一眼「好想玩、好想收集」，第二眼才發現「不對勁」。順序不能反。
- 那點「怪」放在**造型與表情**（空洞眼、鋸齒笑、獠牙），**不是**用陰暗色調或打光去營造。

---

## 2. 從手稿讀出的 DNA

`Collections.pdf` 反覆出現這些特徵，就是本專案的角色視覺基因：

| 母題 | 手稿裡的例子 | 為什麼保留 |
|------|-------------|-----------|
| **動物兜帽 / 偽裝** | 兔帽、狐帽、青蛙帽、貓帽的小孩 | 「怪物穿著人的外衣」——收容 / 偽裝的隱喻 |
| **萬聖節怪談** | 南瓜燈、骷髏、惡魔(鬼)、吸血鬼獠牙、蝙蝠 | 可愛驚悚的核心素材庫 |
| **鈕扣眼 / 三點眼 / 骷髏眼** | 三顆鈕扣當眼睛、空洞的黑眼窩 | 「無神」的眼睛是不安感的來源，不能畫成閃亮大眼 |
| **編號標籤** | `鬼 Nº1`、`Nº.1` 手寫在角色旁 | 直接呼應 SCP 編號怪物設定，是識別符也是氛圍 |
| **歪斜的笑** | 咧到耳根、鋸齒牙、獨眼笑臉 | 天真與詭異各半，別修成標準微笑 |
| **道具敘事** | 手推獨輪車、老鼠夾、藥水罐架、拋硬幣 | 每個角色都在「做一件小事」，畫面自帶故事 |

**自檢**：新的怪物 / 圖示，至少要命中上表兩個母題，否則它不屬於這個世界。

---

## 3. 線條與筆觸

手稿的靈魂在「手」——不完美、會抖、看得出是人畫的。數位化時要刻意保留。

- **輪廓線**：粗、封閉、略帶抖動的手繪外框。**不要**乾淨的向量硬邊。
- **線寬**：外輪廓粗、內部細節細，形成層次（見手稿的惡魔貓、獨眼魚怪）。
- **收尾**：線條端點允許出頭、重疊、不接死，保留草稿呼吸感。
- **填色**：鮮豔平塗（cel）為主，允許蠟筆 / 紙質手感紋理；可有柔和卡通打光與**發光 / bloom**。
- **禁止**：寫實陰影、擬真反光、3D 高模質感、乾淨向量插畫風、**壓抑的暗調光影**。

> 準則：**寧可「看起來像鉛筆掃描進來的」，也不要「看起來像 App Store 圖示」。**

---

## 4. 用色（角色是畫面裡唯一的彩色）

- **只有角色與可互動物上飽和色**：Runner / Hunter、蒐集物件、逃脫門、可壓制高亮、聲音波紋。
- 在純白線稿世界上，任何一塊飽和色都**最大化跳出** → 玩家永遠一眼鎖定「人」與「該互動的東西」。
- **陣營色編碼**：Runner 一個招牌色（全場最跳）；多名 Hunter 一組協調亮色（像玩家色），一眼分得出誰是誰、又看得出同隊。
- **萬聖節糖果盤**：南瓜橙、糖果紫、毒藥綠、泡泡糖粉、鬼火青——鮮但不吵，色相彼此區隔。
- **警示紅**專留給「危險 / 聲音 / 被包夾信號」（呼應 GDD 聲音→包夾）。角色**盡量避開純紅**，別稀釋這個訊號。

---

## 5. 角色設計原則

1. **矮身比例（約 2~3 頭身）**：圓滾滾的 Q 版身形，四肢短。
2. **臉是重點，眼睛決定氣質**：空洞、鈕扣、鋸齒——用「缺陷」製造個性，不要迪士尼大眼。
3. **一個記憶點就好**：每隻怪物只需一個強識別特徵（獨眼、南瓜頭、獠牙、兜帽），不要堆料。
4. **可愛在先，怪在後**。
5. **會編號**：重要怪物 / Runner 帶手寫風 `Nº` 標籤，作為世界觀縫線。

**Runner（編號怪物）**：手稿裡最「可愛驚悚」的那一隻氣質——像 `鬼 Nº1` 惡魔貓、獨眼魚怪，上色是**全場最搶眼的招牌糖果色**。主角，最想被抓的明星。
**Hunter（研究人員）**：「人形、成套、有默契」——一組**協調的亮色制服**（像派對玩家色），彼此可辨又一看就同隊。秩序感來自「成套」，不是冷暗。

---

## 6. 動畫

- **逐格手繪感（低幀 / 誇張形變）**：延續 `scripts/player/player_animator.gd` 的逐幀取向；寧可少幀、Q 彈，不要平滑補間。
- **會呼吸的靜止**：待機時輕微晃動 / 抖動，維持「手畫的活著感」。
- **形變優於位移**：擠壓拉伸、誇張預備動作——卡通感優先於物理正確。
- **平台向**：跳躍 / 落地 / 鑽管道的擠壓拉伸要誇張——落地一格壓扁、起跳一格拉長。

---

## 7. 一頁式速查

- ✅ 明亮飽和的萬聖節糖果派對色；可愛在先、怪只是俏皮點綴
- ✅ 手繪抖線、封閉粗輪廓、看得出是人畫的
- ✅ 陣營色編碼（Runner 招牌色 / Hunter 玩家色）；重要怪物帶手寫 `Nº` 編號
- ✅ 動物兜帽 / 萬聖節母題 / 空洞的眼 / 歪斜的笑
- ✅ 逐格 Q 彈、擠壓拉伸
- ❌ 迪士尼大眼、標準微笑
- ❌ 寫實陰影、擬真反光、乾淨向量、3D 質感、暗調光影
- ❌ 用純紅當裝飾（紅只給危險 / 聲音）

---

## 8. 餵圖 AI 處方（角色）

正向：
```
bright vibrant flat-color character, spooky-cute Halloween candy palette,
wobbly hand-drawn ink outline, cel shading, chibi 2~3 heads tall,
playful party-game mascot (Fall Guys / Costume Quest vibe), hollow / button eyes,
crooked toothy grin, animal-hood costume, white background
```
負向：
```
dark, gloomy, desaturated, grey, horror, realistic, photorealistic,
dramatic shadows, dim, big sparkly disney eyes, 3d render
```

> 訣竅：角色圖故意要「鮮豔、白底」；之後合成時壓在黑白線稿場景上，就是上色本模型。
