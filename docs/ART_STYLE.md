# Escape — 視覺風格總則（Art Style Overview）

本文件是《Escape》視覺風格的**總入口**，只放兩邊共用的北極星。細節分兩份子文件：

- **[ART_CHARACTER.md](ART_CHARACTER.md)** — 角色（Runner / Hunter / 可互動物）：鮮豔糖果派對怪物
- **[ART_SCENE.md](ART_SCENE.md)** — 場景（設施 / 背景 / UI）：黑白線稿 SCP 巨構
- **[ART_KEYVISUAL.md](ART_KEYVISUAL.md)** — 主視覺：把上色本模型一次講完的北極星基準圖

## 北極星：上色本模型

> **世界是黑白線稿，角色是唯一被上色的東西。**
> 像一本 SCP 技術速寫本，被一群糖果色的小怪物闖了進來。

| | 場景（世界） | 角色（+可互動物） |
|---|---|---|
| **色** | 純白 + 灰階 + 強黑線，幾乎無彩色 | 鮮豔糖果色，畫面裡唯一的彩色 |
| **感覺** | 冷酷、精密、龐大、不可名狀（SCP） | 可愛驚悚、俏皮、萬聖節糖果（派對） |
| **血統** | 帝国少年 /《BLAME!》/ 大友克洋 | Fall Guys / Costume Quest / 手稿塗鴉 |
| **文件** | [ART_SCENE.md](ART_SCENE.md) | [ART_CHARACTER.md](ART_CHARACTER.md) |

這個模型一次解決兩件事：
1. **可讀性**：飽和角色壓在純白世界上「跳」得最兇 → 玩家永遠一眼鎖定「人」與「該互動的東西」。
2. **不陰暗**：底色是**純白**（最高明度），不是灰暗——解掉「AI 出圖太灰暗」的根源。

---

## 三條跨越角色與場景的共同紀律

1. **手繪至上**：不管黑白或彩色，線條都要「看得出是人畫的」——抖、封閉、有呼吸感。不要乾淨向量、不要 3D 質感。
2. **彩色＝訊號**：飽和色只給角色 / 可互動物 / 事件。場景與裝飾維持黑白，別稀釋這條訊號。**警示紅**再往上收一層，只給危險 / 聲音 / 被包夾（呼應 GDD 聲音→包夾）。
3. **明亮不壓抑**：避免灰暗、muddy、純黑大色塊。暗與景深靠**灰階 / 線密度 / 淡化**表現，不靠壓黑。
