# Escape — 視覺風格指南（Art Style Guide）

本文件定義《Escape》的視覺基調。所有美術、UI、特效、動畫在產出前，都應能回答一句話：

> **它看起來像不像「一隻被畫在收容檔案角落、可愛又讓人不安的編號怪物」？**

風格的錨點是 `concepts/Collections.pdf` 裡的角色手稿。下面所有原則都是從那疊塗鴉反推出來的，不是外加的。

---

## 1. 一句話定調

**手繪塗鴉感的「明亮版可愛驚悚」——派對感的萬聖節糖果店（Spooky-Cute Party）。**

參考坐標是 *Fall Guys*、*Luigi's Mansion* 派對模式、*Costume Quest*、*Overcooked* 那種**鮮豔、飽和、熱鬧**的調性，不是恐怖片。萬聖節的骷髏南瓜吸血鬼都在，但它們是**糖果色的玩偶**，不是嚇人的鬼。

- **明亮 > 陰暗**：整體高明度、有活力（世界是**純白線稿**、角色是**鮮豔糖果色**，見第 4 節上色本模型）。避免灰暗、muddy、壓抑。
- **可愛在先，怪只是點綴**：第一眼是「好想玩、好想收集」，那點「怪」是俏皮的調味，不是恐懼。
- 那點「怪」用在**造型與表情**（空洞眼、鋸齒笑、獠牙），**不是**用陰暗的色調或打光去營造。

這個基調對上遊戲核心：一場熱鬧的貓鼠追逃派對，**被編號的怪物（Runner）是全場最搶眼、最想被抓也最滑不溜手的糖果色明星。**

---

## 2. 從角色手稿讀出的 DNA

`Collections.pdf` 的角色反覆出現這些特徵，它們就是本專案的視覺基因：

| 母題 | 手稿裡的例子 | 為什麼保留 |
|------|-------------|-----------|
| **動物兜帽 / 偽裝** | 兔帽、狐帽、青蛙帽、貓帽的小孩 | 「怪物穿著人的外衣」——收容 / 偽裝的隱喻 |
| **萬聖節怪談** | 南瓜燈、骷髏、惡魔(鬼)、吸血鬼獠牙、蝙蝠 | 可愛驚悚的核心素材庫 |
| **鈕扣眼 / 三點眼 / 骷髏眼** | 三顆鈕扣當眼睛、空洞的黑眼窩 | 「無神」的眼睛是不安感的來源，不能畫成閃亮大眼 |
| **編號標籤** | `鬼 Nº1`、`Nº.1` 手寫在角色旁 | 直接呼應 SCP 編號怪物設定，是識別符也是氛圍 |
| **歪斜的笑** | 咧到耳根、鋸齒牙、獨眼笑臉 | 天真與詭異各半，別修成標準微笑 |
| **道具敘事** | 手推獨輪車、老鼠夾、藥水罐架、拋硬幣 | 每個角色都在「做一件小事」，畫面自帶故事 |

**產出新素材時的自檢**：新的怪物 / 圖示，至少要命中上表兩個母題，否則它不屬於這個世界。

## 3. 線條與筆觸

手稿的靈魂在「手」——不完美、會抖、看得出是人畫的。數位化時要刻意保留這一點。

- **輪廓線**：粗、封閉、略帶抖動的手繪外框。**不要**乾淨的向量硬邊。
- **線寬**：外輪廓粗、內部細節細，形成層次（見手稿的惡魔貓、獨眼魚怪）。
- **收尾**：線條端點允許出頭、重疊、不接死，保留草稿呼吸感。
- **填色**：鮮豔平塗（cel）為主，允許蠟筆 / 紙質的手感紋理；可以有柔和的卡通打光與**發光 / bloom**（讓派對感更亮、更甜）。
- **禁止**：寫實陰影、擬真金屬 / 玻璃反光、3D 高模質感、乾淨的 UI 向量插畫風、以及**壓抑的暗調光影**。

> 準則：**寧可「看起來像鉛筆掃描進來的」，也不要「看起來像 App Store 圖示」。**

## 4. 色彩——「上色本」模型（世界黑白，角色上色）

一句話：**世界是黑白線稿，角色是唯一被上色的東西。** 像一本 SCP 技術速寫本，被一群糖果色的小怪物闖了進來。

這個模型同時滿足兩個看似衝突的需求：**場景**走純白線稿的 SCP 冷感，**角色**維持鮮豔派對感——而且角色在黑白世界上「跳」得最兇，可讀性反而最好。整體**不陰暗**，因為底色是**純白**（最高明度），不是灰暗。

### 4.1 世界（場景 / 設施 / 結構與固定道具）＝單色線稿

- **純白基底**：畫面底是白，不是灰、不是黑。整體高明度、明亮、不壓抑。
- **灰階只給陰影 / 景深**：幾階灰做暗面、AO、把遠景推後。灰是配角，不是主體。
- **強黑線是主角**：粗、實、有力的黑線撐起所有形體（見參考的密集機械線稿）。
- 這一層**幾乎不上彩色**（頂多極淡的單一冷色氛圍），把彩度全數讓給角色。

### 4.2 角色 + 關鍵互動物＝鮮豔糖果色（畫面裡唯一的彩色）

- **只有這些才上飽和色**：Runner / Hunter、要蒐集的物件、逃脫門、可壓制高亮、聲音波紋。
- 在純白線稿世界上，任何一塊飽和色都會**最大化跳出** → 玩家永遠一眼鎖定「人」與「該互動的東西」。
- **陣營色編碼**：Runner 一個招牌色（全場最跳）；多名 Hunter 一組協調亮色（像玩家色），一眼分得出誰是誰。
- **萬聖節糖果盤**：南瓜橙、糖果紫、毒藥綠、泡泡糖粉、鬼火青——鮮但不吵，色相彼此區隔。
- **警示紅**專留給「危險 / 聲音 / 被包夾信號」（呼應 GDD 聲音→包夾），靠發光脈動跳出。

> 鐵律：**彩色＝重要（角色 / 可互動 / 事件）；黑白＝場景。** 別讓場景裝飾也上飽和色，否則會稀釋掉「彩色＝該注意的東西」這條訊號。

## 5. 角色設計原則

1. **矮身比例（約 2~3 頭身）**：手稿全是圓滾滾的 Q 版身形，四肢短。
2. **臉是重點，眼睛決定氣質**：空洞、鈕扣、鋸齒——用「缺陷」製造個性，不要迪士尼大眼。
3. **一個記憶點就好**：每隻怪物只需一個強識別特徵（獨眼、南瓜頭、獠牙、兜帽），不要堆料。
4. **可愛在先，怪在後**：先讓人覺得「想摸」，第二眼才發現「不對勁」。順序不能反。
5. **會編號**：重要怪物 / Runner 帶手寫風的 `Nº` 標籤，作為世界觀縫線。

**Runner（編號怪物）**：手稿裡最「可愛驚悚」的那一隻氣質——像 `鬼 Nº1` 惡魔貓、獨眼魚怪，但上色是**全場最搶眼的招牌糖果色**。是主角，是最想被抓的明星。
**Hunter（研究人員）**：「人形、成套、有默契」——用一組**協調的亮色制服**（像派對裡的玩家色），彼此可辨、又一看就是同隊。秩序感來自「成套」，不是來自冷暗。

## 6. 場景與 UI

- **場景**：收容設施＝**純白 + 灰階 + 強黑線的密集機械線稿**（見第 8 節）。工整龐大、冷靜精密的巨構，與上頭「歪扭鮮豔的小怪物」形成強烈對撞——底是白的，所以明亮不陰暗。
- **管道（Tunnel）**：Runner 的專屬空間，結構仍是線稿，但內壁透出一圈 **Runner 招牌色的微光**做識別（世界裡少數允許的色光），像「牆縫裡發光的塗鴉」——靠色光跳出，不靠變暗。
- **UI / HUD**：延續手稿感——手寫字、便利貼 / 檔案卡的排版、蓋章式圖示。避免現代扁平 material 風。
- **音效提示（聲音小地圖）**：用**警示紅**的手繪波紋 / 墨點呈現，呼應 GDD 的「聲音→包夾」循環。
- **圖示**：像蓋章、像用墨水手繪，不要乾淨線性 icon。

---

## 7. 動畫

- **逐格手繪感（低幀 / 誇張形變）**：延續 `scripts/player/player_animator.gd` 的逐幀取向；寧可少幀、Q 彈，不要平滑補間。
- **會呼吸的靜止**：待機時輕微晃動 / 抖動，維持「手畫的活著感」。
- **形變優於位移**：擠壓拉伸、誇張預備動作——卡通感優先於物理正確。
- **平台向**：橫向視角下跳躍 / 落地 / 鑽管道的擠壓拉伸要誇張——落地一格壓扁、起跳一格拉長。

## 8. 場景與背景呈現（2D 橫向平台）

**視角＝2D 橫向平台（side-scroller）。場景走「A：純白 + 灰階陰影 + 強黑線的密集機械線稿」，只有角色與可互動物上色（見第 4 節上色本模型）。**

**視覺血統**：帝国少年 / 大友克洋（AKIRA）/ 弐瓶勉《BLAME!》一脈的**巨構機械線稿**——密集管線、龐大到壓迫的空間、白底 + 灰階 + 強黑線、隨處的手寫編號標籤（`04`、`4B UP`、`SEALED AIR`）。這正好把 SCP 收容設施的「冷酷、精密、不可名狀」畫出來。

**核心手法：遠近兩套畫法（本節最重要的一條）**

| 層 | 你要的效果 | 畫法 |
|----|-----------|------|
| **遠景 + 背景裝飾** | **空間感錯誤**、SCP 詭譎感 | 多消失點 / 矛盾透視 / Escher 式互相打架的結構，密集管線纏繞、尺度失真到不合理。**線更密更亂、灰階更多**，看得出「有巨大的東西」但讀不懂它的空間邏輯 → 這就是 SCP 的「不可名狀」 |
| **近景（玩家實際走的玩法層）** | **乾淨的線條素描感** | 誠實、可讀的透視；強黑線描出平台 / 牆 / 門 / 管道口，白底 + 少量灰陰影。**素描筆觸但空間邏輯正確**，玩家一眼讀懂哪能站、哪能走 |

> 精髓：**詭譎留給背景，誠實留給腳下。** 遠景用「空間感錯誤」營造 SCP 壓迫，近景用「乾淨素描」保住平台可讀性——兩者都在同一套白 / 灰 / 黑線稿語言裡，所以畫面統一。

### 8.1 視差分層（靠「線密度 + 灰階」分層，不靠彩色）

| 層 | 內容 | 規則 |
|----|------|------|
| **遠景（慢視差）** | 空間感錯誤的巨構、纏繞管線、矛盾透視的深井 | **線最密、灰階最多、對比最低**、微模糊；用「灰 + 密」退後 |
| **玩法層（1:1，主角所在）** | 能站的地板 / 平台、牆、門、管道口 | **強黑線、白底、對比最高**、素描筆觸但透視誠實；凡能互動的都在這層 |
| **前景（快視差，偶爾遮擋）** | 近處大管線、鋼樑、纜線 | 剪影或粗黑線，**半透明或只在邊緣**，絕不擋角色與落點 |

> 鐵律：**玩法層對比最高、線最實；遠景灰而密、退到後面。** 玩家靠「黑線的實 / 虛」判斷哪能踩——別讓遠景的密線看起來像能站的平台。

### 8.2 剖面 = 垂直圍堵

- 樓層堆疊、通風井連上下 → 圍堵從「左右包夾」升級為**上下左右四面收網**；巨構線稿天生適合畫這種深不見底的垂直井。
- **管道口**畫成牆上 / 地上的維修蓋與裂縫（線稿），內壁透 **Runner 招牌色微光**做識別。
- Hunter 通常走樓梯 / 平台繞路（進不了管道），把守通風井出口的**出管硬直**點壓制。

### 8.3 打光與受限視野（白底高明度版）

**大原則：底是純白、整體明亮；受限視野不用「把畫面調暗」來做。**

- **明暗靠灰階與線密度，不靠壓黑**：陰影 / 暗面用幾階灰表現（見參考的灰調），畫面**沒有純黑的大色塊**，維持高明度。
- **光柱 / 天光**：像參考那樣讓白色光束從結構縫隙灌下來，既是氣氛也是把玩法層打亮的手段。
- **受限視野 ≠ 黑暗**：視野外的區域往**淡灰、去細節、線變虛**退（像沒畫完的草稿），而不是變黑。看得出「有東西」，但讀不清 → 保住「看不全」的機制又不陰暗。
- Runner 在遠處＝黑白世界裡**唯一一團招牌色 + 發光輪廓**，靠彩色跳出來（呼應第 4 節上色本模型）。
- **升壓棘輪**（GDD 4.3）：Runner 蒐集越多，設施加**警示紅的脈動燈 / 旋轉警燈**——是給白線稿世界「點上一盞盞紅燈」，升溫而不變陰森。

### 8.4 房間身分（隨機佈局 + 低視野的救命設計）

- 沿用參考的**手寫編號標籤**（`04`、`4B UP`、`SEALED AIR`、`焚化`）直接畫在結構上——既是 SCP 味，也讓玩家喊得出「牠在 4B 往上鑽了」。
- 按機能分區，每區給一個**識別記號 / 標牌樣式**（收容區 / 維修區 / 出口區），黑白世界裡靠**圖形與標籤**區分，小地圖再補色。
- **N+1 扇逃脫門**造型彼此可辨、可數，落在視線高度、不被前景擋。

### 8.5 平台遊戲要避開的坑

- ❌ **假平台**：遠景那堆密線別讓玩家誤以為能站；真平台用一致的「可站」語言（最實的黑線、固定厚度、白色頂面）。
- ❌ 前景遮住角色、落點或門。
- ❌ 背景搶戲：遠景線再密也要**灰、退後**，不能比玩法層實或黑。
- ❌ 場景跑出飽和彩色（彩色只給角色 / 可互動 / 事件）；也別讓純黑大色塊把畫面壓暗。

## 9. 一頁式速查（做任何素材前對照）

**總則：上色本模型——世界黑白線稿，角色是唯一的彩色。**

**角色 / 可互動物（彩色）**
- ✅ 明亮飽和的萬聖節糖果派對色；可愛在先、怪只是俏皮點綴
- ✅ 手繪抖線、封閉粗輪廓、看得出是人畫的
- ✅ 陣營色編碼（Runner 招牌色 / Hunter 玩家色）；重要怪物帶手寫 `Nº` 編號
- ✅ 動物兜帽 / 萬聖節母題 / 空洞的眼 / 歪斜的笑
- ❌ 迪士尼大眼、標準微笑；❌ 用純紅當裝飾（紅只給危險 / 聲音）

**場景 / 設施（黑白）**
- ✅ 純白基底 + 灰階陰影 + 強黑線；帝国少年 /《BLAME!》式密集機械巨構
- ✅ 遠景「空間感錯誤」（矛盾透視）撐 SCP 感；近景「乾淨素描」保平台可讀
- ✅ 手寫編號標籤（`04`、`4B UP`、`SEALED AIR`）畫在結構上
- ❌ 場景上飽和彩色（彩度全讓給角色）
- ❌ 灰暗 / 純黑大色塊壓暗畫面（底要白、要高明度；受限視野用「淡灰虛化」不用變黑）
- ❌ 遠景密線被誤認成能站的平台

## 10. 餵圖 AI 的處方（分兩套：場景 vs 角色）

**場景（黑白線稿 SCP 巨構）**

正向：
```
dense mechanical line-art interior, black-and-white ink illustration, white background,
grey-scale shading only, strong bold black linework, sci-fi megastructure, tangled pipes and machinery,
impossible Escher-like perspective in the background, huge oppressive scale, tiny human for scale,
handwritten panel labels and numbers, Katsuhiro Otomo / Tsutomu Nihei BLAME! / Teikoku Shonen style,
high-key, clean readable foreground platforms
```
負向：
```
color, colored, saturated, painterly, soft, blurry, low-detail, dark, black background,
gloomy, muddy grey, photorealistic, 3d render
```

**角色（鮮豔糖果派對怪物）**——見第 4 節，維持上一版處方：
```
正向: bright vibrant flat-color, spooky-cute Halloween candy palette, wobbly hand-drawn ink outline,
      cel shading, playful party-game mascot, white background
負向: dark, gloomy, desaturated, grey, horror, realistic, dramatic shadows, dim
```

> 訣竅：**場景圖故意要「無色」**（負向放 color），角色圖故意要「鮮豔」。兩者最後合成時，彩色角色自然壓在黑白世界上——這就是上色本模型。
