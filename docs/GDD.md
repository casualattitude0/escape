# Escape — 遊戲設計文件（GDD）

一場不對稱的貓鼠追逃：一群研究人員拖延，一隻編號怪物破壞設施後逃脫。

---

## 1. 世界觀

某個秘密收容設施中，一隻被列管的 **SCP 編號怪物** 掙脫了收容。警報響起，設施封鎖。

- **編號怪物**（Runner）只有一個念頭：**破壞設施的關鍵設備**，然後從出口逃離。
- **研究人員**（Hunter）殺不死牠，也不打算殺死牠 —— 他們要做的是**拖延**：拖到封鎖支援抵達（倒數結束）為止。

設施本身是舞台：由 N 個區塊隨機組裝的房間網路、怪物專用的水平**管道（Tunnel）**、人類專用的**電梯**，以及散落各處、必須被破壞的設施設備。

---

## 2. 角色與陣營

| 陣營 | 角色 | 人數 | 目標 |
|------|------|------|------|
| 拖延方 | 研究人員 **Hunter** | 2 ~ 4 | 拖到倒數結束 |
| 逃脫方 | 編號怪物 **Runner** | 1 | 破壞設施 → 逃脫 |

不對稱設計：**多名 Hunter 對抗單一 Runner**。Runner 更強、能鑽管道、能擊殺人類、**不會死亡**；Hunter 靠人數、資訊共享與區塊鎖定拖住牠。

---

## 3. 勝負條件

**限時倒數**（起始值 90 秒，待調），歸零就結算。

**Runner 獲勝**
- 破壞完所有指定設施 → 從逃脫點離開設施。

**Hunter 獲勝**
- **撐到倒數歸零**、Runner 還沒逃脫 → Hunter 陣營勝利。
- Hunter **殺不死 Runner** —— 擊暈只是把牠從設備旁邊踢開、燒掉牠的時間。**拖延本身就是唯一的進攻手段**。

---

## 4. 核心玩法

### 4.0 核心循環

把裝飾拿掉，這遊戲無法再簡化的一句話：

> **Runner 必須先取得「破壞媒材」、扛著它到設施旁才能破壞 —— 運送途中不能主動擊殺、不能帶貨鑽管道（移動中的暴露），到設施旁連打破壞又要停下（定點的暴露）→ 人類看到就通報、鎖住那個區塊、聚攏包夾 → 三下敲擊擊暈 Runner、逼牠掉貨、燒牠的時間；Runner 用擊殺、管道位移與無敵幀拆散包夾，把破壞做完後逃脫。**

這條循環決定了每個系統的存在理由，設計與調校都以「不破壞它」為最高原則：

| 系統 | 在循環中的角色 |
|------|----------------|
| 取材＋運送媒材（4.1） | 破壞的前置：媒材分散在場、扛著時不能主動擊殺也不能帶貨鑽管道 → **移動中的暴露窗口**，讓「在路上攔截信使」變成真正的追逐 |
| 破壞設施（4.1） | Runner 的推進手段，也是**定點的暴露窗口** → 停下開防護罩連打；Hunter 要先破罩才擊暈得了，乾守設備沒用 |
| 倒數（3.） | 給整場一個單向壓力；每次被擊暈＝燒時間，讓 Hunter「拖延」本身就是進攻 |
| 受限視野（4.2） | 逼 Hunter 分散 → **單人拖不住** |
| 通報 + 區塊鎖定（4.3） | 把「一個人看到」變成「全隊知道」＋ 直接凍住 Runner 的推進，是 Hunter 最強的拖延道具 |
| 小地圖（4.4） | 資訊不對稱的載體：Runner 知道人在哪、Hunter 只知道「有人看到」 |
| 快速移動（4.5） | 管道 vs 電梯，兩套互不相通的機動網路，決定誰能先到哪 |
| 擊暈（4.6） | Hunter 唯一的干預手段；需要 **3 下**＝需要**多人或多次接觸**，單人幾乎做不到 |
| 擊殺 + 無敵幀（4.6） | Runner 拆包夾的節奏工具，不是取勝手段（人類無限復活） |

**核心張力設計原則**：
- **1 個 Hunter 逼近** → 空手時 Runner 能擊殺逼退、能走；**扛著媒材時不能主動擊殺，只能靠走位甩開** —— 但單人湊不滿三下、攔不下信使（單人拖不住是刻意的）。
- **2+ Hunter 包夾** → 三下擊暈在無敵幀之間仍能湊滿 → Runner 必須製造距離，否則破壞進度被打斷。
- 因此每次交手的本質是：**Runner 停在設備旁的這段時間，Hunter 能不能靠通報聚成一群、在破壞完成前湊滿三下、把牠踢開。**

> ⚠️ **要避免的兩種壞結果**：① **太黏**：擊暈太容易、無敵幀太短 → Runner 永遠破壞不完、必輸 → 挫折。② **太鬆**：擊暈無感、攻擊 CD 太短 → Runner 一路平推 → Hunter 無事可做。
> **平衡基調（本次定調）**：**怪物要比人強一點**。人類的勝利感應該來自「協同拖延」而非「單挑贏了怪物」。

### 4.1 破壞設施（Runner 的推進：取材 → 運送 → 破壞）

- **每個 Section（區塊）帶自己的破壞目標**，全場共 **N 個必須被破壞的設施裝置**（數量待定）。破壞一台，Runner 必須先取得一份**破壞媒材（暫名）**、**扛到裝置旁**才能動手。全部破壞完 → 逃脫點開啟 → 離開設施即勝。
- **破壞媒材**：只有一種媒材，**每個 Section 內有 Hunter 人數 ＋ 1 份**，散佈在該 Section 的取材點。破壞那個 Section 的裝置只需**扛一份過去**；多出來的份數是**反龜縮保證** —— N 個 Hunter 最多守死 N 個取材點，**至少有一份永遠拿得到**。Runner **一次只能扛一個**，媒材**一次性消耗：裝置被打爆的瞬間才消失**。

**推進節奏被拆成三段，暴露也跟著拆開：**

1. **取材**（空手趕路）— 快、能鑽管道 → **難抓**。
2. **運送**（扛著媒材）— **不能主動擊殺**（4.6）、**不能帶貨鑽管道**（進管道就掉在管道口，4.5）→ **移動中的暴露窗口**，Hunter 可以**在路上攔截信使**。被逼近時 Runner 只能靠走位甩開。
3. **破壞**（到設備旁**開防護罩＋連打**）— 沿用 4.6 的打擊手感；罩在時 Hunter 打不到 Runner，要先**用錘子把罩打破**才能擊暈牠 → 停下＝**定點的暴露窗口**，見下方〈破壞段的防護罩〉。

- **連打進度是永久棘輪，從不回退**：已經打進裝置的破壞進度**永久保留**，就算 Runner 被擊暈、媒材回歸原處也一樣，下次帶媒材來**接著打**。→ Hunter **沖不掉進度、只能燒你的時間**（正好對應「拖延即進攻」），也讓「保留多少進度」不再是旋鈕。
- **被擊暈（運送或連打途中，湊滿三下）→ 手上媒材回歸原處**（回原點距離是旋鈕，見 7.），得重新取材、重跑運送段才能繼續打。擊暈的代價＝**時間＋一趟重運送**，不是進度歸零；擊暈沿用 4.6 的無敵幀＋衰退，**單人湊不滿三下 → 單人攔不下信使**。中途掉回原處的媒材**沒被消耗**，可再拿（或拿同 Section 另一份）。
- **裝置打爆** → 該份媒材消耗消失，Runner 轉往下一個 Section。
- **暴露的本質變了**：空手的 Runner 幾乎抓不住 —— 所以 Hunter 要抓的是**扛著媒材的信使**（在路上攔）和**停下連打的破壞者**（在設備旁圍）。「守取材點、守電梯口、在運送與破壞那兩段包夾」才是重點，而不是盲追空手怪物。

#### 破壞段的防護罩（解「設備一台、會被守死」）

Runner 在設備旁**不能戰鬥**（扛著媒材、4.6），所以牠靠**防護罩**買到一段受保護的連打，而不是靠打退 Hunter —— 這樣「守設備」得付出「破罩」的代價，**乾守沒用**：

- **開罩**：扛媒材到設備旁按破壞 → **罩子自動升起 ＋ 開始連打**（沿用現有 BREAK；破壞時 Runner 定住不能動，離開＝收罩）。
- **罩在時**：Hunter 的**錘子敲擊打在罩子上（扣罩血），打不到 Runner** —— 不累積擊暈、不擊退；Runner 安心連打，永久棘輪照累積。
- **打破罩子**：罩子有血（被錘 **X** 下破，見 7.）。**沒有時間上限 —— 罩子只會被 Hunter 打破**：
  - **沒人守 → 罩不破 → 一次連打完成**（守不住的設備本來就該讓牠過）。
  - **越多人一起錘 → 破得越快** → 這是「單人拖不住、多人才行」在設備旁的實作：1 個守的破罩很慢、Runner 幾乎打完；3~4 個幾下就破。
- **罩破 → 曝露窗口**：罩子進**冷卻 Y 秒**不能再開（見 7.）。這段時間 Hunter 的敲擊**正常打 Runner** → 湊三下 → 擊暈 → **媒材回歸原處、重跑**（沿用上面的擊暈規則）。Runner 若在湊滿三下前逃走 → **保住媒材**、等冷卻回來再開罩。
- **破壞一台 ＝ 幾個「開罩 → 被破 → 再開罩」循環**，由「設備血量 ÷ 每輪打進的下數」自然決定，不用另設段數。

> ✅ **已定案（本次）**：① 罩子**沒有時間上限**，只會被 Hunter 打破。② Hunter **用現有的錘子敲擊**打罩、不加新鍵（罩在時扣罩血、罩破後打人）。

> ✅ **已定案**：媒材**一次性消耗**（打爆裝置才消失）；數量為**每個 Section（Hunter＋1）份**，作用是反龜縮、不是多趟運送。破壞動作為「連打」（與 4.6 打擊手感共用），連打進度**永久棘輪、不回退**。原本「長按讀條 / 多階段 / 前置條件 / 可重複使用」等問號皆已收斂。

### 4.2 Hunter 的受限視野

- Hunter 的視野是**受限的**（視錐 / 迷霧 / 有限照明，實作：`scripts/ui/fog.gd`），無法一眼看穿整張地圖。
- 這讓單槍匹馬的 Hunter 難以獨自處理 Runner，鼓勵**分頭搜索、通報、包夾**。

### 4.3 通報機制與區塊鎖定

Hunter 看到 Runner 時，可以**通報**：

- 通報 → **鎖定該區塊 n 秒**（Runner 在鎖定期間無法離開／無法推進，細節待定，見下）。
- 鎖定結束後進入**冷卻 m 秒**，冷卻期間該區塊不能再被鎖定。
- 通報同時觸發全隊小地圖警示（見 4.4）。

這是 Hunter 陣營最強的拖延工具，也是「看到」這個行為的價值所在 —— 看到不只是自己知道，而是**直接凍住怪物的推進**。

> **待決**：鎖定的效果是「怪物出不去這個區塊」還是「怪物在這個區塊裡不能破壞設備」？
> - 前者把鎖定變成**圍捕的開場**（人可以趕過來），張力高，但單人通報就能困住怪物 → 可能太黏。
> - 後者只是**燒時間**，比較貼合「拖延」主題，也不違反「單人拖不住」。
> - **原型建議：後者**（或前者但配合較短的 n 與較長的 m）。

### 4.4 小地圖（資訊不對稱）

實作：`scripts/ui/minimap.gd`

| 玩家 | 小地圖上看得到什麼 |
|------|--------------------|
| **Runner（怪物）** | **人類的方向**（持續、被動）→ 怪物永遠知道往哪走能避開人 |
| **Hunter（人類）** | 只有在**有人看到怪物並通報**時，全隊小地圖出現**警示 + 標點**。**永遠看不到隊友。** |

- 「看不到隊友」是刻意的：它讓「包夾」必須靠通報與默契湊出來，而不是看小地圖自動集合。
- **待決**：標點是**怪物的精確位置**還是**區塊／區域**？區域標記較不精確、比較不會變成「掛在小地圖上追」，也和 4.3 的區塊鎖定同一套語彙 —— **原型建議標區塊**。

### 4.5 快速移動（兩套互不相通的網路）

**垂直與水平通道彼此獨立、沒有互相關聯** —— 這是兩個陣營各自的機動特權，不會在中途交會。

| 角色 | 手段 | 軸向 |
|------|------|------|
| **Runner** | **管道滑行（Tunnel Slide）** | **水平** |
| **Hunter** | **電梯** | **垂直** |

#### 管道滑行（Runner 專屬）

- Runner 進入管道口後**自動觸發滑行**，沿管道方向直線高速滑到另一端出口。
- 滑行中**不能轉向**：進哪條管道是**事先**的決策，不是過程中的修正。
- **脫出**有一小段**出管硬直**（起身/落地），此時最脆弱 —— 若 Hunter 守在出口，正是敲擊的好時機。
- Hunter **無法進入管道**，只能繞路或守出口。
- 鑽入／鑽出都會**發出聲音** → 管道是雙面刃：走得快，但**出口可被預判與埋伏**。
- **扛著破壞媒材時可以進管道，但媒材會掉在管道口** —— 想用管道甩開 Hunter，就得放棄這趟的貨（掉在口、能繞回來撿，比被擊暈彈回原處輕）。管道因此是「空手的逃生特權 vs 運送時的取捨」雙重角色。

#### 電梯（Hunter 專屬）

- Hunter 靠電梯做**上下樓層**的快速移動，是人類唯一的機動特權，也是**分頭搜索後重新聚攏**的骨幹。
- 因為 Runner 只能水平快移、Hunter 只能垂直快移，兩者永遠在不同軸上搶時間 —— **「誰先到那台設備」是每一場的主要博弈**。
- **待決**：電梯是否有等待時間／呼叫時間？Runner 能否破壞或呼叫電梯來干擾？（原型建議：先不給 Runner 干擾能力，保持兩套網路乾淨獨立。）

### 4.6 交戰（怪物 vs 人類）

#### Runner（怪物）

- 可以**擊殺人類**。人類**無限復活**（見下），所以擊殺換到的是**時間與空間**，不是「少一個對手」。
- **攻擊 CD 較長** —— 避免站在原地把整群 Hunter 一次清空、讓包夾永遠成不了形。
- **扛著破壞媒材時不能主動擊殺**（手上有東西）—— 這是運送段的核心摩擦：信使打不動、被逼近只能靠走位甩開，Hunter 的攔截才有牙。放下媒材可恢復擊殺，但等於中斷這趟運送。
- **怪物不會死亡。** 人類做不到的事就是殺死牠。

#### Hunter（人類）

- 可以**敲擊怪物**，**累積 3 下 → 擊暈**。
- **怪物在設備旁開防護罩時，敲擊先打在罩上**（扣罩血、打不到怪物）；**罩破後**敲擊才正常累積擊暈（見 4.1〈破壞段的防護罩〉）。同一把錘子、同一個鍵，只是**先破罩、再擊暈**。
- **每次敲擊，怪物會進入 x 秒的無敵時間** —— 這是防止「一個人站原地連敲三下」的關鍵閥門：無敵幀越長，湊滿三下就越需要**多人輪流**或**多次接觸**。
- 人類可蒐集**更強的道具**，差異化維度：
  - **擊暈所需次數**（3 → 2）
  - **擊暈持續時間**（更久）
- **待決**：三下的累積是否會**隨時間衰退**？不衰退＝一個人跟一整場慢慢磨也能擊暈 → 違反「單人拖不住」。**原型建議：加衰退**（例如 n 秒內沒有新的敲擊就歸零）。

#### 平衡基調

> **要讓怪物比人強一點。** 人類的答案永遠是「更多人 + 更好的資訊」，不是「更強的個人」。
> 四個關鍵旋鈕：**無敵幀 x 秒**、**怪物攻擊 CD**、**擊暈持續時間**、**敲擊累積衰退**。見 7.

#### 無限復活與重生點（把「擊殺」變成 Runner 的節奏貨幣）

- **倒地而非瞬間重生**：Hunter 被擊殺後進入短暫倒地（現值 3.0s，`scripts/player/player_health.gd`）才重生。這幾秒就是 Runner 買到的時間。
- **重生點放在地圖邊緣 / 中央樞紐，遠離設施設備**（`scripts/world/world.gd` HUNTER_SPAWNS）。被殺的 Hunter 必須重新跑回戰場，回程距離＝Runner 買到的路線。重生點**絕不靠近目標**，否則等於獎勵自殺守點。
- **擊殺＝節奏貨幣**：配合攻擊 CD，一次擊殺換到「幾秒 + 一條路線」，而不是換到「少一個對手」。

### 4.7 地圖：隨機組裝

- 設計 **N 個區塊**，每場遊戲**隨機組裝**成一張地圖。
- **地圖拼裝後不要太大** —— 這是硬性約束：太大 → 追逃變成通勤、通報與包夾都失效。
- **每個區塊的尺寸要先規定**（統一尺寸或少數幾種規格），否則拼裝規則與連接口會失控。**這是隨機組裝的前置工作，先訂尺寸再畫區塊。**

**待決**：
- 區塊尺寸規格（1 種？2~3 種？）
- 拼裝規則（幾×幾網格？連接口如何對齊？）
- 保證條件：**沒有死路**（死路對追逃遊戲是設計事故）、每張拼裝結果都必須連通、設備與逃脫點的散佈下限距離。

**組裝之外的地圖原則**（沿用）：
- **環路 + 高密度交叉口**，讓每次追逐都有「往左往右」的即時決策。
- **設施設備彼此拉開**：逼 Runner 長距離移動、暴露路線。
- **管道**入口分散、做成 Runner 專屬圖層；**出口可被預判/埋伏**。
- **電梯**位置決定 Hunter 的聚攏速度，是人類版的「管道網」。
- **重生節點置於邊緣 / 中央樞紐、遠離目標**。
- **視野管理**：房間（開闊、易被看穿）與走廊（狹窄、易被堵）的節奏，製造搜索與伏擊的空間差。

## 5. 節奏與張力

- **短時限**是整場的心跳：Runner 要在極短時間內完成所有破壞，Hunter 只要拖住就贏 —— 每一次「擊暈」「鎖定」都直接換算成勝利進度。節奏天生高壓、單向升溫。
- Runner：在「快速推進破壞」與「不被包夾」之間權衡；靠管道、擊殺與無敵幀拆包夾。永遠知道人在哪（小地圖），所以牠的失誤是**貪**，不是**迷路**。
- Hunter：受限視野下必須**協同搜索**，看到就通報、鎖區塊、聚過去輪流敲；就算被擊殺也能靠人數與復活持續施壓、繼續拖時間。看不到隊友，所以他們的失誤是**沒有溝通**。
- 隨著設備一台台被破壞、時間一秒秒減少 —— 局勢自然走向高潮。

**升壓棘輪**（待實作）：每破壞一台設備，Runner 的暴露永久提高一階（輪廓更亮／小地圖提示更頻／通報冷卻縮短）。破壞越多 → 越接近逃脫 → 越藏不住。

## 8. 原型範圍（先砍什麼）

先驗證核心循環（4.0）好不好玩、旋鈕調不調得動。原型階段**先延後**以下：

| 先砍 / 延後 | 原因 | 原型替代 |
|-------------|------|----------|
| 隨機組裝 | 組裝器是獨立工程，會拖慢玩法驗證 | **先手切一張**符合區塊尺寸規格的固定地圖驗證玩法；組裝器等玩法定案再做 |
| 人類強化道具 | 差異化是後期調味 | 所有人都是「3 下擊暈」的基礎版 |
| 升壓棘輪 | 加分項，不是循環的一部分 | 先不做 |
| 多階段破壞（一台分多趟）／媒材分型 | 系統互相干擾到分不出哪裡不好玩 | **單階段：一份媒材＝破壞一台、媒材不分型（任意媒材→任意設備）**。取材→運送→連打這條三段循環是核心、不砍 |

**原型的唯一問題**：在最小地圖（一個環路 + 幾條管道 + 一組電梯 + N 台設備 + Hunter＋1 個取材點）上，2~3 個 Hunter 對 1 個 Runner，倒數計時、Runner **去取材 → 扛媒材運送 → 停下連打破壞**、人類看到就通報鎖區塊、在**運送途中攔截**或在**設備旁包夾**輪流敲三下 —— **在「怪物比人強一點」的前提下，人類靠通報＋攔截＋包夾拖住牠的攻防夠不夠緊張、會不會一面倒？**

這題答對了，再往上疊隨機組裝與道具差異化。
