# Working with this Godot project

Godot 4.7 (Metal/Forward+) on macOS. Multiplayer game (`Net` autoload, host = Runner, joiners = Hunters).

Binary: `/Applications/Godot.app/Contents/MacOS/Godot`

## ⛔ NEVER broadly kill Godot processes

Do **NOT** run `pkill -f "MacOS/Godot"`, `killall Godot`, or any pattern that
matches every Godot process. **The user usually has the editor open** (a
`.../MacOS/Godot --path . --editor` process). A broad `pkill -9` SIGKILLs it —
the window vanishes with **no crash report and no error**, which looks exactly
like a crash and wastes everyone's time diagnosing a "crash" that was self-inflicted.

Instead, to clean up test instances you launched:
- Capture the PIDs you spawn (`HOST=$!`) and kill **only those**: `kill -9 $HOST $CLI`.
- If you must pattern-match, match your **test-only args**, never `--editor`, e.g.
  `pkill -9 -f 'Godot.*-- host'` / `pkill -9 -f 'join=127'`.
- Before assuming a real crash, check `pgrep -fl "MacOS/Godot"` — the editor
  (`--editor`) is the user's; leave it alone.

## Is it a real crash?

A genuine native crash writes an `.ips` to `~/Library/Logs/DiagnosticReports/`
(or `.../Retired/`). If there is **no new `.ips`**, the process was likely
SIGKILLed (e.g. by a stray `pkill`), not crashed. Parse an `.ips` as: first line
is JSON header, rest is a JSON body with `exception`, `faultingThread`, `threads`.

Known real crash on this machine: a **CoreAudio / AudioToolbox** SIGBUS on the
audio thread at startup. Mitigated in `project.godot` with `audio/driver/driver="Dummy"`
(the game has no sound yet — switch back to the platform default when audio is added).

## Validation workflow (headless, no editor needed)

Run from the project root. zsh has `noclobber` on — use `>|` to overwrite logs.

- **Parse-check a script:** `Godot --headless --check-only --script scripts/foo.gd`
  - False positive to ignore: `Identifier not found: Net` — autoloads aren't
    loaded in `--check-only`. Confirm via full import instead.
- **Full import / project validity:** `Godot --headless --editor --quit-after 20`
  (autoloads load here, so `Net` resolves). Grep stderr for `error|failed|parse`,
  filtering out `d3d12|vulkan|freetype|_ensure_cache`.
- **Two-instance networking smoke test** (dev launch hooks exist in `menu.gd`):
  ```sh
  GODOT="/Applications/Godot.app/Contents/MacOS/Godot"
  "$GODOT" --headless --path . --quit-after 300 -- host >| host.log 2>&1 &
  HOST=$!; sleep 3
  "$GODOT" --headless --path . --quit-after 200 -- join=127.0.0.1 >| client.log 2>&1 &
  CLI=$!; sleep 8
  kill -9 $HOST $CLI       # ONLY the PIDs we spawned — never a broad pkill
  ```
  `-- host` auto-starts once one client joins; `-- join=<ip>` connects.
- **Visual checks:** render to a PNG via a throwaway scene
  (`get_viewport().get_texture().get_image().save_png(...)` after
  `await RenderingServer.frame_post_draw`) and read the PNG. Needs the real
  renderer (not `--headless`).

## Assets / generated files

- `scenes/player_frames.tres` (SpriteFrames) is generated — edit the `ANIMS`
  table in `tools/generate_player_frames.py` and re-run, don't hand-edit.
- `scenes/level.tscn` is generated by `tools/generate_level.py`.
- CJK text needs a loadable system font: macOS PingFang lives in a protected
  "Reserved" folder FreeType can't load. `scenes/ui_font.tres` lists loadable
  fonts (Hiragino Sans GB, Heiti, etc.); PingFang is deliberately excluded.
